# SecureVault for Raycast

快速搜索主表和附表、预览非敏感信息、查看完整字段并复制值。敏感信息通过“在 SecureVault 中打开此记录”回到网页获取；网页锁定时，解锁后自动继续打开目标记录。

## 安装与配置

需要 macOS、Raycast，以及 Node.js **22.22.2 或更高版本**。本扩展独立于 SecureVault 的网页依赖。

1. 构建并启动包含本次接口更新的 SecureVault。在网页中解锁保险库。
2. 在“接入应用”创建名为 Raycast 的应用，访问级别选“只搜索”，勾选需要查询的数据集，并保存应用 ID 和密钥。
3. 在项目根目录执行：

   ```sh
   npm ci --prefix extensions/raycast
   npm run dev --prefix extensions/raycast
   ```

   Raycast 的开发命令会安装本地扩展并监听修改。安装完成后搜索 `Search SecureVault`；可自行为该命令设置别名 `vault` 或快捷键。

4. 首次打开命令时填写服务网页地址、应用 ID 和应用密钥。本机默认地址为 `http://127.0.0.1:4173`；远程部署填写 HTTPS 网页地址，沿用 SecureVault 反向代理和 `SECUREVAULT_PUBLIC_ORIGIN` 配置。地址不填写 `/api`、记录链接或凭据。

应用没有数据集授权时，扩展会显示授权提示。保险库封印、凭据失效或授权停用/过期时，按提示回到 SecureVault 处理，然后按 `⌘R` 刷新。

数据集菜单会分别显示“正在加载数据集”“数据集加载失败”“未授权数据集”或实际的数据集选项。搜索无结果或单条记录预览失败不会清空已授权的数据集。若无法加载，按 `⌘K` 选择“检查连接与授权”，可查看实际服务地址、授权数据集数量或 HTTP 错误；该检查不会显示应用密钥，也不读取敏感字段。

## 使用

- 输入关键词即可检索。空查询列出当前授权范围内的未过期记录，没有收藏功能。
- 搜索使用服务器已有的 AND、精确、前缀、后缀和正则规则；附表索引和展示字段一起参与搜索，也可输入 `附表.字段名:值` 或 `supplement.字段名:值`。
- 搜索栏右侧选择数据集；`⌘⇧F` 打开目录、多个标签、数据模型、数据集及过期记录筛选。目录包含子目录，多个标签取交集（例如客户A + 生产），筛选可清除。模型选项仅从已授权的数据集生成，以模型 ID 区分同名模型。
- 选中结果后右侧预览主表和关联附表；命中字段标注“命中”。普通字段显示在详情中，不参与搜索。
- Enter 查看完整记录，在字段列表中选择字段并按 Enter 复制其值。搜索结果也可按 `⌘C` 打开“复制字段”菜单。
- `⌘O` 在浏览器打开对应的 SecureVault 记录；无需重新搜索，也不会自动解密。`⌘R` 刷新；`⌘→` / `⌘←` 翻页，每页 40 条。
- “查看数据集信息”展示名称、目录、多标签、引用模型的名称与版本，以及数据集说明；没有说明时也可查看基本信息。

记录标识、字段标签、顺序、列表可见性及搜索排序复用服务器配置。附表别名命中优先显示在结果摘要中；详情保留多行内容、JSON、`0` 与 `false`。

结果列表使用紧凑摘要，不重复显示每条记录的数据集来源；来源在右侧预览中展示。普通单行字段按键值排列，多行和 JSON 内容保留代码块；附表另作分区。数据集选项显示可选名称、目录和全部标签；标签按数组顺序以 ` / ` 连接，仅在同名选项需要区分时添加 ID 后缀。旧服务缺少多标签字段时回退读取单环境字段；显式空数组表示无标签。

扩展只发送 GET 请求，不提供导入、编辑或敏感字段解密操作。记录和元数据只保存在当前命令内存，不写入本地缓存；敏感、隐藏、忽略字段不进入展示或复制动作。链接只包含记录 ID，应用凭据仅在 API 请求头中传递，重定向请求会被拒绝。

## 开发与验证

```sh
npm run typecheck --prefix extensions/raycast
npm run lint --prefix extensions/raycast
npm test --prefix extensions/raycast
npm run build --prefix extensions/raycast
cargo build --locked --manifest-path server/Cargo.toml
python3 samples/scripts/raycast_check.py
```

HTTP 回归同时验证 httpyac 实际脚本的名称定位、多标签和共享模型实例隔离。回归使用 `samples/.build/` 下的临时保险库，不读取或改动已有数据。网页记录跳转测试包含在项目根目录的 `npm test` 中。

`lint` 使用 Raycast 的 ESLint 配置和 Prettier 检查本地源码及测试。项目里的 `author` 是本地占位身份；如需发布到 Store，先替换为自己的有效 Raycast 用户名，再运行 `npx ray lint` 的完整发布校验。扩展尚未发布到 Store。

## 新增只读接口

`GET /api/client/datasets` 使用现有 `X-App-Id` / `X-App-Key` 认证，只返回授权数据集的可选名称、目录、标签数组、引用模型 ID/名称/版本、数据集说明、非敏感字段定义、公开逻辑 KEY 和展示配置。模型的取数说明和全局模型目录仍仅对管理会话开放，扩展不获取这些内容。它不开放 `/datasets`、目录管理、统计或其他管理接口，也不改变现有记录搜索、详情或解密接口的权限。

网页记录链接为 `/#record=记录ID`，适用于已有管理会话以及先解锁后查看。无效或不存在的记录沿用网页错误提示；成功处理后移除定位片段。
