# 连接 SecureVault

先启动更新后的 SecureVault，在网页中解锁，然后进入“接入应用”。

创建 Raycast 应用，访问级别选“只搜索”，授权需要查询的数据集。将生成的应用 ID 和密钥填写到右侧设置。

服务地址填写网页地址，例如 `http://127.0.0.1:4173`。远程服务使用 HTTPS；地址不包含 `/api` 或记录链接。

应用密钥轮换后更新扩展设置；无需提供保险库主密码。

`⌘⇧F` 可组合目录、多个标签和数据模型筛选；所选标签全部满足才命中。数据集菜单显示名称、目录和标签，“查看数据集信息”可读引用模型名称、版本及数据集说明。共享模型不会扩大应用的数据集授权。
