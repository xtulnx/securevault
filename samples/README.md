# SecureVault 演示示例

这里提供可重复初始化的演示数据。产品、商户、团队、域名和密钥均为虚构内容；密钥值以 `DEMO_ONLY_` 开头，地址使用 `example.test` 域名。

## 初始化与启动

在项目根目录执行：

```sh
make demo
```

脚本启动独立服务 `http://127.0.0.1:4180/`，生成随机主密码，调用 HTTP API 创建数据集、上传原始文件、完成字段映射和导入，再验证演示状态。初始化结束后服务继续运行，页面可直接使用。

默认输出全部位于 `samples/.runtime/`，不会访问项目原有的 `data/`。该目录已被 Git 忽略，包含：

| 文件 | 用途 |
| --- | --- |
| `credentials.json` | 本次生成的随机主密码和地址 |
| `data/` | 加密数据库和保险库元数据 |
| `manifest.json` | 数据集、记录及应用 ID，创建时返回的应用密钥 |
| `validation.json` | 导入结果与自动功能检查报告 |
| `server.log`、`server.pid` | 服务日志与进程号 |

已有演示库时，初始化脚本会拒绝覆盖。停止服务后，可用 `make demo-serve` 重启；重启后在页面输入 `credentials.json` 中的主密码解锁。可用 `make demo DEMO_PORT=4181` 修改端口。

停止演示服务：

```sh
kill "$(cat samples/.runtime/server.pid)"
```

如需全新体验，先停止服务，将 `samples/.runtime/` 移至一个备份目录，再执行 `make demo`。每次全新初始化都会生成新的密码、记录 ID 和应用密钥。

## 数据集与原始数据

初始数据共 99 行，配置全量同步删除 1 行后保留 **98 条记录**，分布在 **8 个数据集**；4 条记录标记过期，默认检索显示 94 条。数据库含 308 个加密字段，其中包括敏感字段和隐藏字段。

| 目录 | 环境 | 条数 | 文件 | 演示内容 |
| --- | --- | ---: | --- | --- |
| 游戏业务/SDK/产品 | 正式 | 48 | `raw/games_prod.json` | 同一游戏多平台、复合 KEY、密集列表、长 URL、换行说明、JSON 标签、列表隐藏字段 |
| 游戏业务/SDK/产品 | 测试 | 8 | `raw/games_test.json` | 同目录不同环境；与正式环境重复的业务编号互不影响 |
| 游戏业务/SDK/产品 | 预发布 | 8 | `raw/games_staging.json` | 三环境切换 |
| 支付业务/商户 | 正式 | 12 | `raw/merchants.csv` | 中文 CSV 表头映射、业务编号、敏感密钥、隐藏证书 |
| 基础设施/云服务 | 正式 | 8 | `raw/cloud_services.xlsx` | XLSX 导入、区域复合 KEY、数值 0、多行维护说明 |
| 系统集成/Webhook | 测试 | 6 | `raw/webhooks.json` | JSON 字符串路径抽取、嵌套隐藏字段、保存映射模板 |
| 团队协作/运行手册 | 无环境 | 6 | `raw/knowledge.json` | 无环境、无敏感字段、多行正文和数组标签 |
| 平台配置/同步示例 | 测试 | 2 | `raw/inventory_initial.json`、`raw/inventory_sync.json` | 全量同步删除缺失项、Schema 演进、布尔值 |

`raw/datasets.json` 保存完整 Schema、索引/展示/隐藏/敏感分区、逻辑 KEY、列表顺序、格式和源字段映射，可作为新数据集配置参考。JSON/CSV 文本文件可通过 `python3 samples/scripts/generate.py` 重新生成；XLSX 原始文件已提供，可直接上传。`cloud_services_source.json` 是 XLSX 的同值 JSON 原始来源。

## 建议体验顺序

1. 打开演示页面：总览应显示 98 条记录、8 个数据集。全部数据默认为 94 条，可切换分页。
2. 点击「游戏业务」或「SDK」，验证父目录包含子目录数据；选正式、测试或预发布查看环境筛选。
3. 选正式游戏数据集，查看「星海远征（Android）」：SDK 版本已通过重复 KEY 更新为 `3.3.1`。原始 `games_prod.json` 中仍为 `3.2.0`，对照可看到更新效果。
4. 打开详情：索引、展示、受保护字段分区清晰；列表隐藏的「内部备注」仍在详情可见。自动生成的记录主键不出现在页面文字中。
5. 点击「按需查看」，解密「应用密钥」，验证倒计时和自动恢复掩码；尝试复制按钮。隐藏字段仅显示掩码，无解密入口。
6. 勾选「包含过期记录」：可找到正式游戏「轨道先锋（Harmony）」、测试游戏「风之旅团（Harmony）」、最后一个商户以及「容器集群」。可点「恢复有效」体验状态切换。
7. 打开「数据集管理」：查看/调整中文标签、字段顺序、列表格式和可见性。可导出 JSON 或 CSV，默认导出不包含受保护字段。
8. 选「系统集成/Webhook」导入 `raw/webhooks.json`，选择已保存的模板查看 `config` 的 JSON 路径抽取；每个钩子以 `hook_id` 为 KEY。
9. 选正式游戏导入 `raw/games_skip_existing.json`，勾选「跳过已存在的唯一 KEY」，版本应保持 `3.3.1`；取消勾选会更新为该文件中标明的演示版本。导入 `raw/games_update.json` 可恢复 `3.3.1`。
10. 选「平台配置/同步示例」导入 `raw/inventory_initial.json`，恢复三个配置；再导入 `raw/inventory_sync.json` 并勾选「删除本批次不存在的旧记录」，只留下两个配置。
11. 查看「接入应用」中的只读、可解密、停用、已过期四种状态；尝试编辑授权数据集或轮换密钥。权限验证命令见下方。
12. 切换明暗主题，缩放窗口检查列表和详情弹窗。点击「立即封印」，输入随机主密码解锁。演示会话采用常规解锁，保持工具默认 30 分钟空闲及 4 小时会话上限。

操作会改变演示库，原始文件保持不变。下方命令和 `validation.json` 中的计数描述初始化后的状态。

## 检索示例

先清除环境和目录筛选，保持「包含过期记录」关闭，再在搜索框输入：

| 查询 | 初始结果 | 特性 |
| --- | ---: | --- |
| `category:=游戏业务 gid:=2001 platform:=Android` | 3 | 空格 AND、数字精确匹配、不同环境 |
| `product_id:^GAME-2001` | 12 | 前缀匹配 |
| `product_id:$HARMONY` | 14 | 后缀匹配，排除两条过期记录 |
| `merchant_id:~^MCH-300[1-3]$` | 3 | 正则匹配 |
| `version:=3.3.1` | 1 | 展示字段查询与匹配突出 |
| `alias:星海` | 13 | 中文搜索，跨游戏和商户数据集 |
| `region:=cn-shanghai` | 5 | 不同数据集的同名索引字段 |
| `DEMO_ONLY_` | 0 | 受保护值不参与公开搜索 |

使用「查看当前目录可查询索引字段」可点击字段名，将查询前缀插入搜索框。

## 应用接入与自动验证

```sh
python3 samples/scripts/api_demo.py
```

该命令使用本次生成的应用 ID 和密钥，验证只读应用仅能检索正式游戏与运行手册、无权解密或访问云服务；支付应用只能解密支付数据集；停用及过期应用被拒绝。只读范围初始为 54 条（包含过期）。演示密钥仅在本地生成，不写入原始文件或 Git。

初始化检查还验证了：JSON/CSV/XLSX 实际上传和导入、唯一 KEY 更新/跳过、全量同步、Schema 新增、查询与分页、过期筛选、掩码和解密、隐藏字段、公开导出、封印和错误密码拒绝。
